1. Create + activate a merchant

Calls merchant-service directly: POST /api/merchants then PUT /{id}/status?status=ACTIVE.

2. Issue a card

Calls issuer-service directly: POST /api/cards. Card number/CVV are only ever returned here, at issuance.

3. Run a transaction through the whole chain

Calls pos-terminal-service: POST /api/pos/transaction, which calls transaction-service, which calls merchant → acquirer → network → issuer.
